How to Scan Both Sides of a Driver's License onto One Page on iPhone

Last updated 2026-10-22 · Paperkeep Pro feature

Rental applications and new-job paperwork often ask for a copy of your ID, front and back, on a single page. Paperkeep Pro's ID card mode takes the two sides one after the other and lays them out at real size (85.6 × 54 mm) on one A4 page. A regular scan, with each side on its own page, works without Pro.

First, with iOS's built-in tools

  1. The “Scan Documents” option in the Files or Notes app can capture the front and then the back.
  2. You end up with two pages, one per side, each enlarged to fill the page.
  3. iOS has no layout that puts both sides on one page at true size, so for a single-sheet copy you'd normally use a copier's ID copy mode.

With Paperkeep

  1. On the main screen, tap the card-shaped “ID Card” button next to “Scan”.
  2. Front side first, back side second; then hit “Save” in the camera.
  3. On the “New Scan” screen, check both sides and fix either one with “Crop” or “Rotate” if needed, then tap “Save”. The saved PDF holds both sides at real size on one A4 page.
  4. Open the document and use “Tools” → “Export…” to share the PDF, or choose “Print” if you need paper right away.

Tips for this document

  • Write the purpose and date in the margin, such as “For ABC Apartments rental application, 10/21/2026”, so the copy is harder to reuse elsewhere. Paperkeep Pro's “Highlight & Write” → “Text” tool does this.
  • Glare wipes out printed details. Avoid overhead lights and tilt the card slightly until the reflection disappears.
  • Lock the whole library with “Lock Paperkeep” (free) or keep IDs in a locked folder (Pro).
